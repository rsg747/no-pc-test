# N&O PC Run-and-Grade (747 PCWU + PC)

Open `index.html` (GitHub Pages). To update, replace `NO_PC_Run_and_Grade.html`; the loader always pulls the newest copy.

This GitHub build keeps sessions in each browser. To move a PCWU to the PC device, export "PCWU record for the PC (.json)" from the PCWU debrief and use "Import PCWU file" in PC setup.
The Claude-hosted copy shares one N&O PC data store, so the PC finds the PCWU by employee number automatically.

## TV presentation
Upload the `decks/` folder next to the app. "Present on the TV" in the Brief tab loads the oral bank or walk-around images from it.
Mirror the iPad to the Apple TV first (Control Center → Screen Mirroring). The TV shows only the slide; Reveal shows the answer or the planted finding.
